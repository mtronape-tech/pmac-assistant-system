Привет! Мне нужно составить детальное ТЗ для следующей задачи. 
- Я хочу создать MCP сервер и приложение помощник наладчика станков с ЧПУ. 
- В качестве данных будет очень большое количество справочников, руководств и учебников в разных форматах. Также будет несколько конфигураций для станков с ЧПУ (папки с файлами разных расширений). 
- Система должна отвечать на вопросы. 
- Главный функционал, у системы будет доступ к контроллеру ЧПУ. Нужно реализовать управление контролером.
- Управление контроллером пока можно имитировать, так как нет информации о том как с ним связываться.
- Система должна уметь собирать данные и строить по ним графики. Данные собираются опросом контроллера с определенной частотой.
- Должна уметь анализировать графики и составлять рекомендации по параметрам.
- Все приложение должно иметь возможность управляться по API извне.
- У приложения, для начала, должен быть графический интерфейс. Пока только обычный чат для работой с ИИ моделью.
- Реализация на nodejs, ts. 
- Должна быть возможность выбора модели.
- Должна быть возможность добавления данных в MCP.
- Подумай над архитектурой всей системы. Она должна быть оптимальной. Нужна экономия токенов. Возможно получится переложить часть не требовательной к мощности модели работы на простую и бесплатную модель.
- Дай рекомендации. Что можно улучшить? Возможно стоит создавать приложение отдельными модулями со связью через api. Тогда можно некоторые требовательные к ресурсам системы модули написать на другом языке, например, C++ или Go.
